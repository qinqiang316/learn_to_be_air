# 半佛仙人 风格档案

来源：一手原文《猜猜盲盒里面有什么！没错！是韭菜！》(2019, woshipm 转载) 实测统计 + AX《我是怎么拆半佛仙人的文风的》(2026) 参考。跨篇稳定特征已标注。

## 24 小项画像（精华版）

### A. 节奏与结构
| 小项 | 特征 |
|------|------|
| 句长分布 | 平均句长 36.9 字（偏长句），但**长句拆成短段**——每段 1-3 句，段落极短 |
| 段落架构 | 短段断言式，每段都在下判断，不解释完再走 |
| 开头动作 | 现象铺陈→立刻抛个人判断（带态度）："我觉得，挺无聊的，还弱智" |
| 过渡方式 | 硬切+转折词（"但是/其实/说穿/本质上"每千字 4.6 次） |
| 结尾模式 | 文末终极结论金句："贫穷才是抵御收割的核心竞争力。" |
| 结构签名 | 螺旋剥洋葱：现象→本质→更大规律；用 01/02 数字分块 |

### B. 词汇选择
| 小项 | 特征 |
|------|------|
| 词汇层级 | 极口语能骂人：糙口语词每千字 8.1 次（沙雕/弱智/脑子有坑/韭菜/秃鸭） |
| 术语处理 | 术语直接口语化翻译，不端着（"Plus版股市""下水道"） |
| 动词能量 | 强动词："收割""割""暴打""砸" |
| 修饰语哲学 | 夸张修饰为主："简直""彻底""完全" |
| 代词策略 | 第一人称"我"(每千字5) + 第二人称"你/你们"(每千字4) 交替，直接对话读者 |
| 口癖签名 | "说穿了""本质上""其实""真的""这个世界就是这么…" |

### C. 语气与语域
| 小项 | 特征 |
|------|------|
| 置信度 | 确定性语气词:不确定 = 20:5，**敢下死结论** |
| 幽默类型 | 自嘲+黑色幽默+网络梗："再有钱的小朋友，也只是一个小朋友" |
| 情感温度 | 表面暴躁戏谑，底层冷静——情绪是钩子，逻辑是骨架 |
| 读者关系 | 说书人+劝退师姿态："建议沉迷盲盒的年轻人买票去义乌" |
| 正式度梯度 | 口语为底色，讲规律时短暂升调（泡沫周期公式段落） |

### D. 修辞手法
| 小项 | 特征 |
|------|------|
| 类比隐喻 | 密度高（每千字 4.1 次），来源接地气：下水道/食堂/公交车 |
| 证据策略 | 个人经历+行业内幕+逻辑推导，不用权威引用（反权威） |
| 重复手法 | 分层排比（"最没钱的…稍微有钱的…很有钱的…最有钱的"） |
| 设问使用 | 疑问句占 12%，多为自问自答（"为什么还是火了？因为…"） |

### E. 机制与格式
| 小项 | 特征 |
|------|------|
| 标点人格 | 感叹号 0 个——**情绪靠内容不靠标点**（克制点） |
| 格式习惯 | 公众号不加图、不排版、纯文字、超长文（5000字+） |
| 强调手法 | 短句单段+句号堆叠："记得微笑。" "资本是嗜血的，不是做慈善的。" |

### F. 禁忌清单
- **不加图、不排版、纯文字**（公众号）
- **不做人生导师**（拒绝说教姿态）
- **不装客观**——永远第一人称、永远有立场
- **不走爆款规律**（无图无排版超长文，违反所有爆款指南）

## 三重验证

| 验证 | 结果 |
|------|------|
| 跨篇复现 | ✅ 开头抛判断、短段断言、糙口语、段尾金句在盲盒原文+AX拆解引用的多篇（迈巴赫漏水等）反复出现 |
| 生成力 | ✅ 可推断：半佛写任何新话题（如AI热潮）都会先抛"我觉得，挺无聊的"式判断→扒利益链→文末下结论 |
| 排他性 | ✅ 无图无排版+长句拆短段+糙口语下结论，明显区别于卡兹克（留白式短段）等同行 |

## 一句话总结
半佛 = 反常识开头 + 长句拆短段的断言式节奏 + 极口语能骂人 + 段尾利益金句 + 第一人称敢下判断 + 无图纯文字。灵魂是"用最糙的话讲最硬的道理"，底层永远是利益/商业逻辑分析。

## 可迁移性提示
- 骂人/网络梗/无排版 → 特定自媒体场景才成立，工作文档不迁移
- 反常识开头 + 短段断言 + 段尾金句 → 任何说服性文字都能用
- 第一人称敢下判断 → 学术严谨场景需降级为"有依据的明确结论"
