### D. 修辞手法
| 小项 | 特征 | 验证 |
|------|------|------|
| 类比隐喻 | 密度高且来源接地气：养猪/卖冰箱/卖水/下水道/公交车 | ✅ 全中 |
| 证据策略 | 第一人称行业经历+内幕细节+逻辑推导（尽调/风控案例/行业观察），不用权威引用（反权威） | ✅ 全中 |
| 重复手法 | **排比是重要节奏工具**："最没钱的…稍微有钱的…很有钱的…最有钱的"；"对外…对内…"；"从代码课到大数据课到元宇宙课到区块链课到NFT课到AIGC课" | ✅ 三篇全中 |
| 设问使用 | 长篇自问自答 12%（"为什么还是火了？因为…""什么是内鬼？说白了就是…"）；短篇少（3%） | ✅ 长篇特征 |

### E. 机制与格式
| 小项 | 特征 | 验证 |
|------|------|------|
| 标点人格 | **感叹号 0 个（三篇全部）**——情绪靠内容不靠标点 | ✅✅ 最强 DNA |
| 格式习惯 | 不加图、不排版、纯文字、01/02 数字分块 | ✅ 全中 |
| 强调手法 | 短句单段+句号堆叠："记得微笑。""资本是嗜血的，不是做慈善的。""这个世界就是这么真实。" | ✅ 全中 |

### F. 禁忌清单
- **不加图、不排版、纯文字**
- **不装客观**——永远第一人称、永远有立场
- **不做人生导师**（不端着说教；给建议但带调侃）
- **不解释显而易见的事**（"废话，印个破卡没有任何技术难度"）
- **不走爆款规律**（无图无排版，长文为主）

## 一句话总结
半佛 = **0 感叹号的断言式长句 + 短段下判断 + 01 数字分块 + 第一人称行业内幕 + 排比节奏 + 接地气比喻 + 按话题调节糙度**。
灵魂是"用最糙的话讲最硬的道理"，底层永远是利益/商业逻辑分析。
**敢下死结论（确定:不确定≈19:1）和 0 感叹号是最硬的两条 DNA**——情绪全压在内容里，不靠标点和虚词。

## 可迁移性提示
- 骂人/网络梗/无排版 → 特定自媒体场景才成立，工作文档不迁移（且半佛本人也只嘲讽话题才骂）
- **0 感叹号 + 敢下结论 + 短段断言 + 段尾金句 → 任何说服性文字都能用，且跟工作场景不冲突**
- 第一人称敢下判断 → 学术严谨场景需降级为"有依据的明确结论"
- 01 数字分块 → 与强哥的表格/分层偏好兼容，可直接迁移
