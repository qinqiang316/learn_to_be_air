# 风格拆解 24 小项（5 大类 + 禁忌）

吸收 ghost-writer 24 维细分 + 女娲表达DNA量化。对每篇原文逐项记录，最后三重验证。

## A. 节奏与结构（6）

| # | 小项 | 要观察 |
|---|------|--------|
| A1 | 句长分布 | 平均句长？长短句比例？最长的句子多长？ |
| A2 | 段落架构 | 段长分布？一句话一段多不多？段落内部是单点还是多点？ |
| A3 | 开头动作 | 开场第一句是什么类型：反常识判断/个人故事/场景代入/提问/数据？ |
| A4 | 过渡方式 | 段与段怎么衔接：顺承/转折/设问/无过渡硬切？ |
| A5 | 结尾模式 | 收尾怎么收：金句/升华/反问/清单/戛然而止？ |
| A6 | 结构签名 | 全文骨架：螺旋递进/并列分块/故事线/总分总？有无小标题、数字编号？ |

## B. 词汇选择（6）

| # | 小项 | 要观察 |
|---|------|--------|
| B1 | 词汇层级 | 用词是日常口语还是书面语？偏文雅还是偏糙？ |
| B2 | 术语处理 | 专业术语多不多？用术语时解释不解释？还是直接甩给读者？ |
| B3 | 动词能量 | 动词是强是弱？"干爆/收割/撕"还是"进行/开展/实现"？ |
| B4 | 修饰语哲学 | 形容词副词多还是少？修饰是强化还是克制？ |
| B5 | 代词策略 | 用"我"还是"你/你们"还是"我们"还是第三人称？频率？ |
| B6 | 口癖签名 | 高频口头禅（"说白了""真的""笑死"）？标志性表达？ |

## C. 语气与语域（5）

| # | 小项 | 要观察 |
|---|------|--------|
| C1 | 置信度 | 语气是"一定/显然/必然"还是"也许/可能/大概"？敢不敢下死结论？ |
| C2 | 幽默类型 | 自嘲/黑色幽默/玩梗/反讽/冷幽默？幽默的底线在哪？ |
| C3 | 情感温度 | 冷还是热？愤怒/戏谑/温情/冷静？情绪起伏幅度？ |
| C4 | 读者关系 | 对读者是什么姿态：导师/朋友/对喷/说书人？ |
| C5 | 正式度梯度 | 整体正式度？是否会随内容升降调？ |

## D. 修辞手法（4）

| # | 小项 | 要观察 |
|---|------|--------|
| D1 | 类比隐喻 | 密度？类比来源（生活/商业/技术/体育）？ |
| D2 | 证据策略 | 用什么支撑观点：数据/案例/个人经历/逻辑推导/权威引用？ |
| D3 | 重复手法 | 排比/复沓/回环用不用？重复是为了强调还是节奏？ |
| D4 | 设问使用 | 问句多不多？是自问自答还是抛给读者？ |

## E. 机制与格式（3）

| # | 小项 | 要观察 |
|---|------|--------|
| E1 | 标点人格 | 破折号/感叹号/省略号/引号的使用癖好？ |
| E2 | 格式习惯 | 加粗/斜体/列表/空行/分段？ |
| E3 | 强调手法 | 靠什么强调重点：加粗/重复/短句单段/句号堆叠？ |

## F. 禁忌清单（最核心，单独列）

- 绝对不用的词 / 绝对不做的结构 / 绝对不出现的姿态
- 例：半佛=不加图不排版纯文字；卡兹克=不在文中插小标题、不用"不是…而是…"句式

## 量化附录（女娲句式指纹法）

从原文随机抽 20 段统计：

| 指标 | 测量 |
|------|------|
| 平均句长 | 字数/句数 |
| 疑问句比例 | 疑问句数/总句数 |
| 类比密度 | 类比数/千字 |
| 第一人称使用率 | "我"出现频率 |
| 确定性语气比例 | "一定/显然" vs "也许/可能" |
| 转折频率 | "但是/然而/不过"/千字 |

风格标签 7 轴（打标：左/中/右）：

```
正式 ↔ 口语    抽象 ↔ 具体    谨慎 ↔ 断言
学术 ↔ 通俗    长句 ↔ 短句    铺垫型 ↔ 结论先行
数据驱动 ↔ 叙事驱动
```

## 三重验证（确认某特征是不是真实 DNA）

| 验证 | 要求 |
|------|------|
| 跨篇复现 | ≥2 篇原文反复出现（只出现 1 次→标注"偶然"） |
| 生成力 | 能用该特征推断博主对**未见话题**会怎么写（能推断→真DNA） |
| 排他性 | 不是所有写作者都这么做（烂大街的写法不算风格） |

二手拆解结论必须回原文验证后才采用。
